HTML คืออะไร

ไฟล์ .html คือไฟล์ตัวหนังสือธรรมดา เปิดด้วย Notepad ก็อ่านได้ แต่พอเปิดด้วยเบราว์เซอร์ (Chrome หรือ Edge) เบราว์เซอร์จะอ่านตัวหนังสือนั้นแล้ววาดออกมาเป็นหน้าจอ มีหัวข้อ ตาราง ปุ่ม และกราฟ

ทำไมไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล

โปรแกรมอย่าง HIS ต้องมีเครื่องกลาง (เซิร์ฟเวอร์) ที่เก็บข้อมูลของทั้งโรงพยาบาล ทุกเครื่องต่อเข้าไปถามข้อมูล แต่โปรแกรมจัดซื้อทำงานคนละแบบ ทุกอย่างเกิดในเบราว์เซอร์บนเครื่องที่พี่เปิดอยู่

2 เรื่องที่ควรรู้เพิ่ม

  • โปรแกรม "จำ" ไฟล์ที่ลากครั้งล่าสุดได้ โดยเก็บไว้ในเบราว์เซอร์ของเครื่องนั้นเอง ถ้าเปลี่ยนเครื่อง เปลี่ยนเบราว์เซอร์ หรือล้างประวัติเบราว์เซอร์ ต้องลากไฟล์ใหม่

สร้างโปรแกรมด้วย Antigravity กับ AI

พี่ไม่ต้องพิมพ์โค้ดเอง ให้ AI ใน Antigravity เขียนให้ งานของพี่คือ อธิบายให้ชัด แล้ว เปิดดูว่าถูกไหม ทำซ้ำไปเรื่อย ๆ จนได้โปรแกรมที่ต้องการ

  1. สร้างโฟลเดอร์ใหม่ สำหรับโปรแกรมนี้ เช่น Documents\โปรแกรมของพี่โอม หนึ่งโปรแกรมใช้หนึ่งโฟลเดอร์ จะได้ไม่ปนกัน
  2. เปิด Antigravity กด File → Open Folder แล้วเลือกโฟลเดอร์นั้น
  3. ในช่องแชทของ AI วาง แบบฟอร์มที่ 1 ด้านล่าง เติมข้อความในวงเล็บ [ ] ให้ครบ แล้วส่ง AI จะสร้างไฟล์ .html ไว้ในโฟลเดอร์ให้
  4. เปิดดูผล คลิกขวาที่ไฟล์ในรายการไฟล์ด้านซ้าย เลือก Reveal in File Explorer แล้วดับเบิลคลิกไฟล์ จะเปิดขึ้นมาใน Chrome หรือ Edge
  5. ลองใช้จริง ถ้ายังไม่ตรงใจ ใช้แบบฟอร์มที่ 2 หรือ 3 บอก AI ให้แก้ แก้เสร็จแล้วกลับไปที่เบราว์เซอร์ กด F5 เพื่อโหลดไฟล์ใหม่
ห้ามลืม

อย่าส่งไฟล์ Excel ข้อมูลจริงของโรงพยาบาลให้ AI และอย่าวางไฟล์จริงไว้ในโฟลเดอร์ที่เปิดใน Antigravity เพราะ AI อ่านไฟล์ในโฟลเดอร์ได้ ส่งแค่ชื่อคอลัมน์ กับตัวอย่าง 2–3 แถวที่แต่งขึ้นเอง ก็พอ AI ไม่จำเป็นต้องเห็นข้อมูลจริงเพื่อเขียนโปรแกรม และยังช่วยประหยัดโควตาด้วย

อ่านโค้ดให้พอรู้เรื่อง

ประหยัดโควตา AI แผนฟรี

ทุกข้อความที่ส่ง และทุกไฟล์ที่ AI ต้องอ่าน กินโควตาทั้งหมด ยิ่งยาวยิ่งหมดเร็ว 5 ข้อนี้ช่วยให้ใช้ได้นานขึ้น

  1. ขอทีละเรื่อง แต่อธิบายให้ครบในข้อความเดียว การคุยไปกลับหลายรอบเพื่อเติมรายละเอียดกินโควตามากกว่า
  2. เปลี่ยนเรื่องเมื่อไหร่ ให้เริ่มแชทใหม่ แชทยาว ๆ ทำให้ AI ต้องอ่านเรื่องเก่าทั้งหมดซ้ำทุกครั้งที่ตอบ
  3. เขียน "สเปก" เก็บไว้ในไฟล์ข้อความ สั้น ๆ ว่าโปรแกรมทำอะไร ใช้ไฟล์อะไร คอลัมน์อะไร คำนวณยังไง เวลาเริ่มแชทใหม่ก็บอก AI ให้อ่านสเปกก่อน AI จะเข้าใจทันทีโดยไม่ต้องอ่านโค้ดทั้งไฟล์ (โปรแกรมจัดซื้อมีไฟล์ README.md ทำหน้าที่นี้อยู่)
  4. งานเล็กแก้เอง เปลี่ยนคำ เปลี่ยนสี เปลี่ยนตัวเลข ใช้ Ctrl + F หาแล้วแก้ในหน้าต่างโค้ดของ Antigravity ได้เลย ไม่เสียโควตา
  5. สำรองไฟล์ก่อนแก้ครั้งใหญ่ คัดลอกไฟล์ไว้อีกชุด ตั้งชื่อตามวันที่ เช่น dashboard-2569-10-05.html ถ้า AI แก้พัง จะย้อนกลับได้ทันที โดยไม่ต้องเสียโควตาให้ AI ซ่อม

GitHub คืออะไร และทำไมคนทำถึงใช้

GitHub คือเว็บสำหรับเก็บโค้ด คล้าย Google Drive แต่จำทุกเวอร์ชันที่เคยแก้ ถ้าแก้พังก็ย้อนกลับไปเวอร์ชันก่อนได้ ประวัติการแก้ของโปรแกรมจัดซื้อมี 20 ครั้งแล้ว ทุกครั้งย้อนดูได้

เหตุผลหลักที่ใช้คือ คนทำแก้โปรแกรมจากหลายเครื่อง แก้เสร็จที่เครื่องไหนก็ส่งขึ้น GitHub (เรียกว่า push) แล้วอีกเครื่องดึงลงมา (เรียกว่า pull) ทุกเครื่องได้ไฟล์ล่าสุดตรงกัน ไม่ต้องส่งไฟล์ผ่านไลน์หรือ USB และไม่สับสนว่าไฟล์ไหนใหม่กว่า

GitHub ยังมีบริการชื่อ GitHub Pages ที่ทำให้ไฟล์ HTML บน GitHub เปิดเป็นเว็บได้ฟรีผ่านลิงก์ พี่โอมเลยเปิดโปรแกรมได้เลยโดยไม่ต้องมีไฟล์ในเครื่อง และได้เวอร์ชันล่าสุดเสมอ

อะไรอยู่บน GitHub และอะไรไม่อยู่

อยู่บน GitHub

  • โค้ดของโปรแกรม (ไฟล์ HTML)
  • คู่มือ README
  • เป็นแบบสาธารณะ คนที่มีลิงก์เห็นโค้ดได้ แต่โค้ดไม่มีข้อมูลยาหรือข้อมูลผู้ป่วย

ไม่อยู่บน GitHub

  • ไฟล์ Excel ข้อมูลจริงของ รพ. ตั้งค่าไว้ไม่ให้อัปโหลดขึ้นไป
  • ไฟล์ที่พี่ลากมาวางในหน้าโปรแกรม อยู่ในเบราว์เซอร์ของพี่เท่านั้น

ไม่จำเป็นต้องมีก็ได้ เริ่มจากแบบง่ายก่อน แล้วค่อยขยับเมื่อพร้อม

แบบง่าย: เก็บไฟล์ไว้ในเครื่อง

  • เก็บไฟล์ .html ในโฟลเดอร์ ดับเบิลคลิกเปิด
  • ส่งให้คนอื่นทางไลน์หรืออีเมลได้ คนรับกดดาวน์โหลดแล้วดับเบิลคลิก
  • ถ้าเก็บใน Google Drive ต้องดาวน์โหลดลงเครื่องก่อน เพราะ Drive จะแสดงเป็นตัวหนังสือโค้ด ไม่วาดเป็นหน้าจอ

แบบมีลิงก์: GitHub Pages

  • ทำผ่านหน้าเว็บได้ทั้งหมด ไม่ต้องพิมพ์คำสั่ง
  • ได้ลิงก์ที่เปิดจากเครื่องไหนก็ได้
  • ฟรี แต่โค้ดจะเป็นแบบสาธารณะ

ขั้นตอนทำลิงก์ด้วย GitHub Pages

  1. สมัครบัญชีที่ github.com ชื่อบัญชีที่ตั้งจะไปอยู่ในลิงก์ เลือกให้ดี
  2. กดปุ่ม + มุมขวาบน → New repository ตั้งชื่อโปรเจกต์ เช่น my-drug-tools เลือก Public แล้วกด Create repository
  3. กดลิงก์ uploading an existing file ลากไฟล์ .html มาวาง แล้วกด Commit changes (ตั้งชื่อไฟล์ว่า index.html จะได้ลิงก์ที่สั้นกว่า)
  4. ไปที่ Settings → Pages ช่อง Branch เลือก main แล้วกด Save
  5. รอ 1–2 นาที รีเฟรชหน้า Pages จะเห็นลิงก์ขึ้นมา หน้าตาแบบนี้ https://ชื่อบัญชีพี่.github.io/my-drug-tools/

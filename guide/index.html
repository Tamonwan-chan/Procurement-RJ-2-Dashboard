HTML คืออะไร

ไฟล์ .html คือไฟล์ตัวหนังสือธรรมดา เปิดด้วย Notepad ก็อ่านได้ แต่พอเปิดด้วยเบราว์เซอร์ (Chrome หรือ Edge) เบราว์เซอร์จะอ่านตัวหนังสือนั้นแล้ววาดออกมาเป็นหน้าจอ มีหัวข้อ ตาราง ปุ่ม และกราฟ

เทียบง่าย ๆ คือใบสั่งยา ตัวใบเป็นแค่ตัวหนังสือ แต่คนจัดยาอ่านแล้วทำตามได้ ไฟล์ HTML ก็คือ "ใบสั่ง" ที่เบราว์เซอร์อ่านแล้วทำตาม

  • โปรแกรม "จำ" ไฟล์ที่ลากครั้งล่าสุดได้ โดยเก็บไว้ในเบราว์เซอร์ของเครื่องนั้นเอง ถ้าเปลี่ยนเครื่อง เปลี่ยนเบราว์เซอร์ หรือล้างประวัติเบราว์เซอร์ ต้องลากไฟล์ใหม่

เขียน PRD ก่อนสั่ง AI

PRD ย่อมาจาก Product Requirements Document คือเอกสารที่บอกว่าโปรแกรมต้องทำอะไร เขียนก่อนให้ AI เริ่มสร้าง

พี่คุ้นกับงานจัดซื้ออยู่แล้ว PRD ก็คือ TOR หรือสเปกของโปรแกรม สเปกชัด ของที่ได้ก็ตรง สเปกคลุมเครือ ต้องตีกลับแก้กันหลายรอบ AI ก็เหมือนผู้ขาย ทำตามที่เขียนไว้ ไม่ได้ทำตามที่เราคิดในใจ

ได้ตรงใจตั้งแต่รอบแรก

แค่บอก AI ให้อ่าน PRD.md ไม่ต้องอธิบายใหม่ตั้งแต่ต้น

ใช้ได้กับทุกเครื่อง ทุก AI

เปลี่ยนเครื่อง หรือโควตาหมดแล้วไปใช้แชทในเว็บ ก็ใช้ PRD เดิมได้

สร้างไฟล์ PRD.md

  1. ใน Antigravity คลิกขวาที่ว่างในรายการไฟล์ด้านซ้าย เลือก New File ตั้งชื่อ PRD.md
  2. กดคัดลอกแบบฟอร์มด้านล่าง วางลงในไฟล์ เติมข้อความในวงเล็บ [ ] แล้วกด Ctrl + S เพื่อเซฟ

ไฟล์ .md คือไฟล์ข้อความธรรมดา เครื่องหมาย # คือหัวข้อ - คือข้อย่อย และ [ ] คือช่องติ๊กที่ยังไม่เสร็จ ข้อ 8 เป็นข้อกำหนดที่ใช้กับทุกโปรแกรม ไม่ต้องแก้

# PRD: เช็กยาใกล้หมดอายุ

## 1. ปัญหาที่อยากแก้
ทุกเดือนต้องเปิด inventory_exp.xls แล้วไล่หา lot ที่ใกล้หมดอายุเอง ใช้เวลานานและพลาดได้

## 2. คนใช้
เภสัชกรคลังยา 2 คน เปิดดูเดือนละ 1–2 ครั้ง

## 3. ข้อมูลที่ใช้
ไฟล์: inventory_exp.xls (export จาก HIS)
คอลัมน์:
- meditem = รหัสยา
- expdate = วันหมดอายุ
- lotno = เลข lot
- sumqty = จำนวนคงเหลือ (กล่อง)
- unitcost = ราคาทุนต่อกล่อง
- packqty = จำนวนบรรจุต่อกล่อง
ตัวอย่างข้อมูล (แต่งขึ้น ไม่ใช่ข้อมูลจริง):
1001, 2027-01-31, A123, 20, 150, 100
1002, 2026-12-15, B456, 5, 820, 10
1003, 2028-06-30, C789, 12, 95, 500

## 4. สิ่งที่โปรแกรมต้องทำ
- [ ] ลากไฟล์ inventory_exp.xls มาวางแล้วอ่านได้
- [ ] แสดงเฉพาะ lot ที่หมดอายุภายใน 6 เดือนนับจากวันนี้
- [ ] รวมมูลค่ายาที่ใกล้หมดอายุทั้งหมด
- [ ] ค้นหาด้วยรหัสยาได้

## 5. วิธีคำนวณและเงื่อนไข
- มูลค่า = sumqty × unitcost
- เหลือไม่ถึง 3 เดือน = แถวสีแดง, 3–6 เดือน = แถวสีเหลือง
- ยอดติดลบให้นับเป็น 0

## 6. หน้าจอ
- ด้านบน: จำนวน lot ที่ใกล้หมดอายุ และมูลค่ารวม
- ตาราง: รหัสยา, lot, วันหมดอายุ, เหลืออีกกี่วัน, จำนวน (กล่อง), มูลค่า
- เรียงจากหมดอายุก่อนไปหลัง

## 7. ยังไม่ทำในรอบนี้
- ชื่อยา (ต้องใช้ Meditem.xls เพิ่ม ทำรอบหน้า)
- ส่งออก Excel

## 8. ข้อกำหนดที่ใช้ทุกโปรแกรม (ไม่ต้องแก้)
- เป็นไฟล์ HTML ไฟล์เดียว ชื่อ index.html รวม CSS และ JavaScript ไว้ในไฟล์เดียว
- เปิดได้ด้วยการดับเบิลคลิกในเบราว์เซอร์ ไม่ใช้เซิร์ฟเวอร์ ไม่ใช้ฐานข้อมูล
- ข้อความบนหน้าจอเป็นภาษาไทย
- ผู้ใช้ลากไฟล์ Excel มาวางเอง ห้ามใส่ข้อมูลจริงไว้ในไฟล์ HTML
- ข้อมูลที่ลากมาวาง ต้องไม่ถูกส่งออกไปที่ไหน

## 9. ตรวจยังไงว่าเสร็จ
- [ ] ลากไฟล์ที่มี 3 แถวตัวอย่างข้างบน ถ้าเปิดวันที่ 2026-10-05
      ต้องเห็น 2 lot: B456 สีแดง (เหลือ 71 วัน) และ A123 สีเหลือง (เหลือ 118 วัน)
- [ ] C789 ต้องไม่แสดง เพราะเหลือเกิน 6 เดือน
- [ ] มูลค่ารวมต้องเป็น 7,100 บาท (5 × 820 + 20 × 150)
ข้อ 9 สำคัญที่สุด

ใส่ตัวอย่างที่รู้คำตอบล่วงหน้า เช่น มูลค่ารวมต้องได้ 7,100 บาท พอ AI สร้างเสร็จ พี่ลองแล้วเทียบได้ทันทีว่าคำนวณถูกไหม ไม่ต้องเชื่อ AI อย่างเดียว

ไม่รู้จะเขียนยังไง ให้ AI ช่วยถาม

ถ้านึกไม่ออกว่าจะเติมอะไร ให้สร้าง PRD.md ด้วยแบบฟอร์มเปล่าไว้ก่อน แล้วใช้คำสั่งนี้ AI จะถามทีละข้อเหมือนสัมภาษณ์ แล้วเขียนลงไฟล์ให้ การคุยรอบนี้ใช้โควตาบ้าง แต่น้อยกว่าการให้ AI เขียนโค้ดผิดแล้วแก้หลายรอบมาก

สร้างโปรแกรมด้วย Antigravity กับ AI

พี่ไม่ต้องพิมพ์โค้ดเอง ให้ AI อ่าน PRD แล้วเขียนให้ งานของพี่คือ ดูแล PRD ให้ชัด แล้ว ลองใช้ตามข้อ 9 ทำซ้ำไปเรื่อย ๆ จนได้โปรแกรมที่ต้องการ

  1. สร้างโฟลเดอร์ใหม่ สำหรับโปรแกรมนี้ เช่น Documents\เช็กยาใกล้หมดอายุ หนึ่งโปรแกรมใช้หนึ่งโฟลเดอร์ จะได้ไม่ปนกัน
  2. เปิด Antigravity กด File → Open Folder แล้วเลือกโฟลเดอร์นั้น
  3. เขียน PRD.md ตามบทที่แล้ว
  4. ในช่องแชทของ AI วาง คำสั่งที่ 1 ด้านล่าง AI จะอ่าน PRD แล้วสร้างไฟล์ index.html ในโฟลเดอร์ให้
  5. เปิดดูผล คลิกขวาที่ index.html ในรายการไฟล์ด้านซ้าย เลือก Reveal in File Explorer แล้วดับเบิลคลิก ไฟล์จะเปิดใน Chrome หรือ Edge แล้วลองตามข้อ 9 ของ PRD ทีละข้อ
  6. ยังไม่ตรง ใช้คำสั่งที่ 2 หรือ 3 อยากได้ความสามารถเพิ่ม เพิ่มลงใน PRD ข้อ 4 ก่อน แล้วค่อยใช้คำสั่งที่ 2 แก้เสร็จแล้วกลับไปที่เบราว์เซอร์ กด F5 เพื่อโหลดใหม่
ห้ามลืม

อย่าวางไฟล์ Excel ข้อมูลจริงไว้ในโฟลเดอร์ที่เปิดใน Antigravity เพราะ AI อ่านไฟล์ในโฟลเดอร์ได้ เก็บไฟล์จริงไว้ที่อื่น แล้วลากมาวางในโปรแกรมตอนใช้งานเท่านั้น

วิธีดูข้อความ error: เปิดไฟล์ในเบราว์เซอร์ กด F12 เลือกแท็บ Console ถ้ามีข้อความสีแดง ให้คลุมดำ คัดลอก แล้ววางในคำสั่งที่ 3 ข้อความนี้ช่วยให้ AI แก้ถูกจุดในรอบเดียว ไม่ต้องเดาหลายรอบ

ดับเบิลคลิกแล้วไฟล์ไม่เปิดในเบราว์เซอร์: คลิกขวาที่ไฟล์ เลือก Open with แล้วเลือก Chrome หรือ Edge

ประหยัดโควตา AI แผนฟรี

ทุกข้อความที่ส่ง และทุกไฟล์ที่ AI ต้องอ่าน กินโควตาทั้งหมด ยิ่งยาวยิ่งหมดเร็ว 5 ข้อนี้ช่วยให้ใช้ได้นานขึ้น

  1. ขอทีละเรื่อง แต่อธิบายให้ครบในข้อความเดียว การคุยไปกลับหลายรอบเพื่อเติมรายละเอียดกินโควตามากกว่า
  2. เปลี่ยนเรื่องเมื่อไหร่ ให้เริ่มแชทใหม่ แชทยาว ๆ ทำให้ AI ต้องอ่านเรื่องเก่าทั้งหมดซ้ำทุกครั้งที่ตอบ
  3. ให้ PRD.md ตรงกับโปรแกรมเสมอ เวลาเริ่มแชทใหม่ บอก AI ว่า "อ่าน PRD.md ก่อน" AI จะเข้าใจโปรแกรมทันทีโดยไม่ต้องอ่านโค้ดทั้งไฟล์ (Dashboard จัดซื้อใช้ไฟล์ README.md ทำหน้าที่นี้)
  4. งานเล็กแก้เอง เปลี่ยนคำ เปลี่ยนสี เปลี่ยนตัวเลข ใช้ Ctrl + F หาแล้วแก้ในหน้าต่างโค้ดของ Antigravity ได้เลย ไม่เสียโควตา
  5. สำรองไฟล์ก่อนแก้ครั้งใหญ่ คัดลอกไฟล์ไว้อีกชุด ตั้งชื่อตามวันที่ เช่น dashboard-2569-10-05.html ถ้า AI แก้พัง จะย้อนกลับได้ทันที โดยไม่ต้องเสียโควตาให้ AI ซ่อม

  • ระหว่างรอ ยังเปิดโปรแกรมที่ทำไว้แล้วใช้งานได้ตามปกติ เพราะโปรแกรมไม่ต้องพึ่ง AI ตอนใช้งาน
  • ใช้เวลานี้เขียนสิ่งที่อยากแก้ลงใน PRD.md รอบหน้าสั่ง AI ได้ในข้อความเดียว

ใช้แชท AI ในเว็บ (ฟรี)

  • เช่น gemini.google.com, chatgpt.com, claude.ai
  • คัดลอกเนื้อหาใน PRD.md ไปวางในแชท แล้วขอให้เขียน index.html ตาม PRD AI จะตอบเป็นโค้ด กดคัดลอก วางลงใน index.html ใน Antigravity แล้วเซฟ
  • เหมาะกับโปรแกรมเล็ก ไฟล์ใหญ่อย่าง Dashboard จัดซื้ออาจยาวเกินที่แชทฟรีรับได้

ชื่อบัญชีอยู่หน้าลิงก์เหมือนบ้านเลขที่ ลิงก์ของโปรแกรมจะขึ้นต้นด้วยชื่อบัญชีของคนที่เอาโปรแกรมขึ้น GitHub เสมอ ถ้าวันหนึ่งพี่มีบัญชี GitHub ของตัวเองแล้วเอาโปรแกรมขึ้นไป ลิงก์ก็จะขึ้นต้นด้วยชื่อบัญชีของพี่แทน

GitHub คืออะไร และทำไมน้องแป้งถึงใช้

GitHub คือเว็บสำหรับเก็บโค้ด คล้าย Google Drive แต่จำทุกเวอร์ชันที่เคยแก้ ถ้าแก้พังก็ย้อนกลับไปเวอร์ชันก่อนได้ ประวัติการแก้ของโปรแกรมจัดซื้อมี 20 ครั้งแล้ว ทุกครั้งย้อนดูได้

เหตุผลหลักที่ใช้คือ น้องแป้งแก้โปรแกรมจากหลายเครื่อง แก้เสร็จที่เครื่องไหนก็ส่งขึ้น GitHub (เรียกว่า push) แล้วอีกเครื่องดึงลงมา (เรียกว่า pull) ทุกเครื่องได้ไฟล์ล่าสุดตรงกัน ไม่ต้องส่งไฟล์ผ่านไลน์หรือ USB และไม่สับสนว่าไฟล์ไหนใหม่กว่า

GitHub ยังมีบริการชื่อ GitHub Pages ที่ทำให้ไฟล์ HTML บน GitHub เปิดเป็นเว็บได้ฟรีผ่านลิงก์ พี่โอมเลยเปิดโปรแกรมได้เลยโดยไม่ต้องมีไฟล์ในเครื่อง และได้เวอร์ชันล่าสุดเสมอ

อะไรอยู่บน GitHub และอะไรไม่อยู่

อยู่บน GitHub

  • โค้ดของโปรแกรม (ไฟล์ HTML)
  • คู่มือ README
  • เป็นแบบสาธารณะ คนที่มีลิงก์เห็นโค้ดได้ แต่โค้ดไม่มีข้อมูลยาหรือข้อมูลผู้ป่วย

  • ไฟล์ที่พี่ลากมาวางในหน้าโปรแกรม อยู่ในเบราว์เซอร์ของพี่เท่านั้น

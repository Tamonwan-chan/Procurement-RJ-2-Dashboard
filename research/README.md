ตั้งแต่ 24 พ.ย. 2569 โปรแกรมนี้พัฒนาเพื่อใช้ในงานวิจัยเชิงพัฒนา (research and development) ด้วย ไม่ใช่เครื่องมือทำงานอย่างเดียว ไฟล์นี้บอกว่าหลักฐานแต่ละอย่างอยู่ที่ไหน

- **ผู้วิจัย / ผู้เขียนบทความ:** ทีมผู้ใช้โปรแกรมที่ รพ.ราชวิถี 2 (รังสิต) · ผู้วิจัยหลัก ทีม วารสาร และการยื่น EC รอคำตอบ (ข้อ 46 ใน `ประเด็นที่รอยืนยันจากพี่โอม.md`)
- **AI ช่วยพัฒนา:** เขียนโค้ดและเอกสารร่วมกับ Claude (Anthropic) ผ่าน Claude Code · ทุก commit ที่ AI ช่วยมีบรรทัด `Co-Authored-By: Claude …` (246 จาก 263 commit ณ 24 พ.ย. 69 · นับใหม่ `git log --format=%B | grep -c "Co-Authored-By: Claude"`) · ผู้พัฒนาตรวจและสั่ง merge ทุกครั้ง

|---|---|---|

| กฎการคำนวณ | `README.md` | วิธีคิดตัวชี้วัด |

## หลักฐานที่ไม่อยู่ใน repo นี้ (ห้าม commit)
repo นี้เป็นสาธารณะ ข้อมูลวิจัยจริงเก็บนอก repo หรือในโฟลเดอร์ `research-data/` ที่ git ไม่เก็บ (ตั้งไว้ใน `.gitignore`):
- โครงร่างวิจัย (protocol) ฉบับร่าง และเอกสาร EC
- แบบสอบถามที่ตอบแล้ว ผลจับเวลา รายชื่อผู้ตอบ หรือข้อมูลใดที่ระบุตัวคนได้
- ตัวเลขจริงจาก HIS หรือจากข้อมูลกลาง (Google Sheet: วันเวลาและผู้ออกเอกสาร) ที่ดึงมาวิเคราะห์

ข้อมูลกลางบันทึกผู้ออกเอกสารแต่ละใบ เป็นข้อมูลส่วนบุคคลของเจ้าหน้าที่ ใช้ในงานวิจัยได้เมื่อ EC อนุมัติและผู้ใช้ยินยอมเท่านั้น

## ทุกครั้งที่ขึ้นเวอร์ชันใหม่ (tag บน master)
1. รันชุดทดสอบทั้งหมดใน `tests/` (smoke, memo-test, creditor-test, gas-test, shared-test)
2. `node tests/screens.js` → `research/screens/<tag>/`
3. เพิ่มหัวข้อเวอร์ชันใน CHANGELOG.md: วันที่ สิ่งที่เปลี่ยน (ประเภท A / B · ข้อในบันทึกคำถาม · #issue) และผลทดสอบ
4. commit ทั้งหมดพร้อม tag

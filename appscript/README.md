# ที่เก็บข้อมูลกลาง (Google Sheet + Apps Script) · issue #44

Google Sheet ของ **บัญชี Google คลัง (inventory)** เก็บข้อมูลที่ทุกเครื่องใช้ร่วมกัน หน้าโปรแกรมคุยกับ Sheet ผ่าน web app ในโฟลเดอร์นี้

**ห้ามอยู่ใน repo (สาธารณะ):** ข้อมูลจริง · รหัสเข้าถึง · ที่อยู่ web app · `.clasp.json` (อยู่ใน `.gitignore`) · `~/.clasprc.json` (token ล็อกอิน)
**เก็บในเครื่องเหมือนเดิม ไม่ขึ้น Sheet:** DATA Template.xlsx (ลายเซ็น) · ไฟล์ HIS · ตราครุฑ

| ตรวจรับ | รย. / รยว. | |

ทุกแท็บล็อกแบบเตือน (แก้ได้แต่มีคำเตือน): ให้โปรแกรมเป็นผู้เขียน คนเปิดดูอย่างเดียว

## ตั้งค่าครั้งแรก (บัญชีคลัง + ผู้ดูแล)

1. **[บัญชีคลัง]** เปิด Chrome profile ของบัญชีคลัง (แยกจากบัญชีส่วนตัว) → Google Drive → สร้าง Google Sheet ชื่อ `ระบบจัดซื้อ – ข้อมูลกลาง` และโฟลเดอร์ `สำรองข้อมูลแต่ละเครื่อง`
2. **[บัญชีคลัง]** ใน Sheet: ส่วนขยาย (Extensions) → Apps Script → ตั้งชื่อโปรเจกต์ `ระบบจัดซื้อ – web app`
3. **[บัญชีคลัง]** แชร์ Sheet ให้บัญชีผู้ดูแลเป็น "ผู้แก้ไข" (script ที่ผูกกับ Sheet แชร์ตามไปด้วย) · คัดลอก Script ID จาก Apps Script → การตั้งค่าโปรเจกต์ (Project Settings)
4. **[ผู้ดูแล]** เปิด Apps Script API ที่ https://script.google.com/home/usersettings (ครั้งเดียวต่อบัญชี) แล้วในโฟลเดอร์นี้:
   สร้างไฟล์ `.clasp.json` ในโฟลเดอร์นี้เอง (ไม่ใช้ `clasp clone` เพราะจะดึงไฟล์เปล่าจาก Google มาทับ `Code.gs`):
   ```
   {"scriptId":"<Script ID>","rootDir":"."}
   ```
   แล้ว
   ```
   clasp login
   clasp push -f
   ```
   (`-f` ให้ใช้ `appsscript.json` ใน repo ทับของเดิม · git ไม่เก็บ `.clasp.json` · ถ้าเครื่องใช้ร่วมกับคนอื่น `clasp logout` เมื่อเสร็จ)
5. **[บัญชีคลัง]** โหลด Sheet ใหม่ → เมนู `ระบบจัดซื้อ` → `ตั้งค่าครั้งแรก` → อนุญาตสิทธิ์ (หน้า "Google ยังไม่ได้ยืนยันแอปนี้" เป็นเรื่องปกติ: ขั้นสูง (Advanced) → ไปที่โปรเจกต์) → หน้าต่างแสดง **รหัสเข้าถึง** คัดลอกเก็บไว้
6. **[บัญชีคลัง]** Apps Script → ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment) → ประเภท เว็บแอป → ดำเนินการในฐานะ **ฉัน (บัญชีคลัง)** · ผู้มีสิทธิ์เข้าถึง **ทุกคน (Anyone)** → คัดลอก URL ที่ลงท้าย `/exec`
7. ส่ง URL และรหัสเข้าถึงให้ผู้ใช้ทาง**แชตส่วนตัว** ห้ามโพสต์ในกลุ่ม ห้ามใส่ใน repo
8. **ทดสอบ:** เปิด `<URL>?action=ping&key=<รหัส>` ในเบราว์เซอร์ ต้องเห็น `"ok":true` · ใส่รหัสผิดต้องเห็น `"error":"key"` · ดู Apps Script → การดำเนินการ (Executions) ว่าทำงานในนามบัญชีคลัง

## เชื่อมต่อหน้าโปรแกรม (แต่ละเครื่อง)

1. เปิดหน้าโปรแกรม → ปุ่ม **ข้อมูลกลาง** (แถบ "ข้อมูลที่ใช้อยู่")
2. ใส่ ที่อยู่ web app (ลงท้าย `/exec`) · รหัสเข้าถึง · ชื่อผู้ใช้ / เครื่อง (เช่น โอม-โน้ตบุ๊ก แสดงในแท็บ บันทึกการแก้) → **เชื่อมต่อ**
3. ครั้งแรกของเครื่อง: ข้อมูลเดิมในเครื่องเก็บสำเนาไว้ แล้วใช้ข้อมูลใน Sheet แทน · Sheet ว่าง = ถามว่าจะส่งข้อมูลของเครื่องนี้ขึ้นเป็นข้อมูลตั้งต้นไหม (ใช้กับ **Sheet ทดสอบ** เท่านั้น)
4. **ซ้อมบน Sheet ทดสอบก่อนทุกครั้ง:** ไฟล์ → ทำสำเนา (Make a copy) ของ Sheet จริง → ในสำเนา ส่วนขยาย → Apps Script → Deploy ใหม่ (สำเนาได้ script และรหัสแยกของตัวเอง: เมนู ระบบจัดซื้อ → สร้างรหัสเข้าถึงใหม่) · ห้ามทดสอบกับ Sheet จริง
5. หน้าโปรแกรมบน GitHub Pages มีปุ่มนี้แล้ว (18 พ.ย. 69) · ซ้อมกับ Sheet ทดสอบ: เปิดหน้าโปรแกรมในหน้าต่าง Incognito (ข้อมูลแยกจากหน้าต่างปกติ)

## อัปเดต script ภายหลัง

- ผู้ดูแล: แก้ `Code.gs` ใน repo → `clasp push` (เปลี่ยนเฉพาะโค้ดล่าสุด หน้าโปรแกรมยังใช้เวอร์ชันที่ deploy ไว้)
- **บัญชีคลัง:** Deploy → จัดการการทำให้ใช้งานได้ (Manage deployments) → แก้ไข → เวอร์ชัน "ใหม่" → ทำให้ใช้งานได้ · URL เดิม ไม่ต้องแจ้งเครื่องใหม่
- ผู้ดูแลไม่ `clasp deploy` ทับ deployment จริงจนกว่าจะยืนยันว่ายังทำงานในนามบัญชีคลัง

## รหัสหาย หรือเครื่องหาย

บัญชีคลัง: เมนู `ระบบจัดซื้อ` → `สร้างรหัสเข้าถึงใหม่` แล้วใส่รหัสใหม่ทุกเครื่อง รหัสเดิมใช้ไม่ได้ทันที

## API (สำหรับหน้าโปรแกรม)

POST เป็น `text/plain` เนื้อหา JSON `{ key, by, action, ... }` (ดูหัวไฟล์ `Code.gs`)
`ping` · `pull` · `put` (เทียบ `baseRev` กันเขียนทับงานคนอื่น) · `reserve` (จองเลขแบบเทียบก่อนเขียน ภายใต้ lock)
รูปแบบเลขที่และการขึ้นปีใหม่คิดที่หน้าโปรแกรมที่เดียว

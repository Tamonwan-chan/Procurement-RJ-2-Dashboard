PRD เขียนว่า "นับที่ GPU" — ในไฟล์จริงพบคอลัมน์ gpucode ในชีต "ทะเบียน" (Generic Product Unit) แต่มีแค่บางรายการที่ถูกกำหนดรหัสนี้ไว้ ด้านบนจึงทำเป็นตัวเลือกสลับได้ก่อน รอพี่โอมยืนยันว่าตัวเลขหลักที่จะใช้รายงานคือแบบไหน

จากชีต "จัดหา" — lowrate / highrate / userate

เทียบอัตราการใช้จริง (userate) กับเกณฑ์ต่ำสุด/สูงสุด (lowrate/highrate) ต่อรายการ — มีเฉพาะรายการที่อยู่ในรอบแจ้งความต้องการจัดซื้อรอบนี้

ตารางนี้ตั้งสมมติฐานว่า lowrate/highrate คือ "ช่วงเกณฑ์อัตราการใช้ที่ยอมรับได้" และ userate คืออัตราการใช้จริงปัจจุบัน (ต่ำกว่า lowrate = ใช้ช้ากว่าเกณฑ์, สูงกว่า highrate = ใช้เร็วกว่าเกณฑ์) รอพี่โอมยืนยันความหมายที่ถูกต้องของทั้งสามค่านี้

ไฟล์จริงยังไม่มีคอลัมน์ "gpscode" 14 หลักตามที่ระบุใน PRD — กราฟนี้จึงใช้ "ชื่อกลุ่ม" (A, B, C, ...) จากชีต "คงคลัง" ไปก่อน (มูลค่ารวมบาท ณ รายการที่มีอยู่ในชีตนั้น) รอพี่โอมยืนยันว่ากลุ่มตัวอักษรนี้คือกลุ่มเดียวกับที่จะใช้ผูกรหัส gpscode หรือไม่ หรือมีตารางแม่บท GPSC แยกต่างหากที่ต้องนำมาจับคู่เพิ่ม

ประเด็นที่รอยืนยันจากพี่โอม

  1. 1Import ไฟล์ได้ทุกครั้งที่มีของใหม่ หรือต้อง fix โครงสร้างคอลัมน์ตายตัว เพื่อไม่ให้ hospcode สลับที่กันทุกรอบอ้างอิง PRD: "หน้าหลักแสดงข้อมูล ตาม excel * Import ได้ทุกครั้งมั้ย หรือต้อง fix"
  2. 2เผื่อห้องจ่ายยาเพิ่มปี 2570–71 กี่ห้อง และใช้ชื่อห้องว่าอะไร (mockup เตรียมปุ่มไว้ 1 ห้องเพิ่มก่อน)อ้างอิง PRD: "70 มีห้องจ่ายยาเพิ่มมั้ย" / "ห้องยาน่าจะได้เพิ่มอีกห้องในปี 70-71"
  3. 3สัดส่วน ED/NED ให้นับที่ระดับใด — รายการยา (hospcode) หรือรหัส GPU (ในไฟล์จริงพบว่ามีรหัส GPU ให้แค่บางรายการในชีต "ทะเบียน")อ้างอิง PRD: "คิดเป็นสัดส่วน... โดยนับที่ GPU"
  4. 4"ชื่อกลุ่ม" (A, B, C, ...) ในชีต "คงคลัง" คือกลุ่มเดียวกับที่จะใช้เป็นรหัส gpscode หรือไม่ ถ้าไม่ใช่ ต้องขอตารางแม่บท gpscode มาจับคู่เพิ่มอ้างอิง PRD: "เพิ่มอีก column ต่อท้าย gpscode... มูลค่าคงคลัง 900,000.00 บาท"
  5. 5คอลัมน์ lowrate / highrate / userate ในชีต "จัดหา" หมายถึงอะไรกันแน่ (เกณฑ์อัตราการใช้ต่ำสุด-สูงสุด กับอัตราการใช้จริง ตามที่ mockup นี้ตั้งสมมติฐานไว้ ใช่หรือไม่)อ้างอิง PRD: "อัตราการใช้ยา lowrate, highrate (อยู่ใน แจ้งความต้องการซื้อ)"
  6. 6คลังกลางและหน่วยย่อยมีหน่วยนับต่างกันตามแต่ละรายการ (เม็ด/ขวด/กล่อง) — ต้องการให้แปลงเป็น "หน่วยจัดหา" เดียวกันทั้งระบบหรือไม่ หรือแสดงตามหน่วยจริงของแต่ละรายการแบบนี้ต่อไปอ้างอิง PRD: "ใช้หน่วยจัดหา (เป็น Box/unit)"
  7. 7drug cat — ต้องการให้ key เข้าเองในระบบอย่างเดียว หรือรองรับ import ทับบัญชีเดิม (ชีต "drugcat" ในไฟล์จริงมี 4,335 รายการ มากกว่ารายการต้องจัดซื้อ)อ้างอิง PRD: "drug cat (Key เข้า หรือ import update บัญชีได้)"

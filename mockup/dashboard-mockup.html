ประเด็นที่รอยืนยันจากพี่โอม

ปรับตามที่พี่โอมแจ้งแล้ว:

  • นับรายการยาเฉพาะที่มีสต็อกรวม > 0 และนับรายการละ 1 ครั้ง ไม่นับตามจำนวนห้อง
  • เพิ่มตัวกรองทะเบียน (6 ประเภท) และประเภทบัญชี (12 ประเภท) พร้อม "ทั้งหมด"
  • เพิ่ม "รายการคลังยา" ในแถบมุมมองห้องยา และเตรียมโค้ดรองรับห้องจ่ายยาใหม่ปี 70–71 แล้ว
  • มูลค่าหน่วยย่อย = จำนวน × costrate จากชีตทะเบียน
  • มูลค่าคงคลังแยกตามประเภทบัญชี 12 ประเภท แทน "ชื่อกลุ่ม" / gpscode
  1. 1ห้องจ่ายยาใหม่ปี 70–71 จะใช้ชื่อห้องและชื่อชีตใน Excel ว่าอะไร (โค้ดเตรียมไว้แล้ว เพิ่มชื่อชีตอย่างเดียวก็ใช้ได้)
  2. 2ในสัดส่วน ED : NED — บัญชียาสมุนไพร, ยา Covid 19 และสูตรตำรับ รพ. ควรนับเป็น ED หรือไม่ (ตอนนี้ไม่นับทั้งฝั่ง ED และ NED แต่แสดงแยกในกราฟ) และ "R:restricted list (EDจ)" 2 รายการ ตอนนี้อยู่ในกลุ่ม "ไม่ระบุ" ถูกต้องไหม
  3. 3คอลัมน์ inventory (P) ในชีตรายการต้องจัดซื้อ ไม่ตรงกับชีตคงคลัง 4 รายการ เช่น hospcode 1272010 (P = 4,650 แต่ชีตคงคลัง = 200) — ควรยึดตัวเลขจากที่ไหน (ตอนนี้ยึดชีตคงคลัง)
  4. 4lowrate / highrate / userate ในชีตจัดหา คือเกณฑ์อัตราการใช้ต่ำสุด–สูงสุด เทียบกับอัตราการใช้จริง ใช่หรือไม่
  5. 5ในชีตทะเบียนยังมี "ทะเบียนรังสี" (256 รายการ) และ "ทะเบียนอวัยวะเทียม" แบบไม่มี (IR) (22 รายการ) — ต้องการให้เป็นตัวเลือกด้วยหรือไม่
  6. 6Import ไฟล์ใหม่ได้ทุกครั้งโดยใช้ชื่อชีตและหัวคอลัมน์เดิม — ต่อไปจะมีการเปลี่ยนชื่อชีตหรือหัวคอลัมน์หรือไม่
  7. 7drug cat — ต้องการ key เข้าเองในระบบ หรือ import ทับบัญชีเดิม (ชีต drugcat มี 4,335 รายการ)

ประเด็นที่รอยืนยันจากพี่โอม

  1. 1Import ไฟล์ได้ทุกครั้งที่มีของใหม่ หรือต้อง fix โครงสร้างคอลัมน์ตายตัว เพื่อไม่ให้ hospcode สลับที่กันทุกรอบอ้างอิง PRD: "หน้าหลักแสดงข้อมูล ตาม excel * Import ได้ทุกครั้งมั้ย หรือต้อง fix"
  2. 2เผื่อห้องจ่ายยาเพิ่มปี 2570–71 กี่ห้อง และใช้ชื่อห้องว่าอะไร (mockup เตรียมปุ่มไว้ 1 ห้องเพิ่มก่อน)อ้างอิง PRD: "70 มีห้องจ่ายยาเพิ่มมั้ย" / "ห้องยาน่าจะได้เพิ่มอีกห้องในปี 70-71"
  3. 3สัดส่วน ED/NED ให้นับที่ระดับใด — "GPU" ในโจทย์หมายถึงรหัส Generic Product Unit หรือหมายถึงอย่างอื่นอ้างอิง PRD: "คิดเป็นสัดส่วน... โดยนับที่ GPU"
  4. 4ต้องเพิ่มคอลัมน์ "ราคาต่อหน่วย" ในไฟล์นำเข้า เพื่อคำนวณมูลค่าคงคลังตาม gpscode ให้ตรงจริงอ้างอิง PRD: "มูลค่าคงคลัง 900,000.00 บาท"
  5. 5เกณฑ์ตัดสิน low rate / high rate ใช้ตัวเลขอะไร (เช่น จำนวนเดือนคงคลังคงเหลือ หรือเทียบ % ค่าเฉลี่ยกลุ่มยา)อ้างอิง PRD: "อัตราการใช้ยา lowrate, highrate (อยู่ใน แจ้งความต้องการซื้อ)"
  6. 6drug cat — ต้องการให้ key เข้าเองในระบบอย่างเดียว หรือรองรับ import ทับบัญชีเดิมด้วยอ้างอิง PRD: "drug cat (Key เข้า หรือ import update บัญชีได้)"

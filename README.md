## สถานะปัจจุบัน

- ลากไฟล์ที่ export จาก HIS มาวางได้หลายไฟล์พร้อมกัน โปรแกรมจำประเภทไฟล์จากหัวคอลัมน์ (ไม่ต้องตั้งชื่อไฟล์ให้ตรง)
- จำข้อมูลนำเข้าครั้งล่าสุดของแต่ละไฟล์ไว้ในเบราว์เซอร์ (IndexedDB) — ไฟล์ที่ไม่ได้นำเข้าใหม่จะใช้ข้อมูลเดิม ข้อมูลอยู่เฉพาะเครื่อง/เบราว์เซอร์ที่นำเข้า
- Top 10 และตารางแสดงเป็นกล่อง: คงคลัง (กล่อง) + (ชั้น 1 + ชั้น G) ÷ packsize
- ส่งออก Excel: hospcode, generic, tradename, content, packsize, list want, inventory, total floor, floor1, floor G, floor 1 IPD, lot / expdate (รวมทุก lot), distribute, manufact, ised, ndc24, medaccnation_name, medrgttype_name, drugcode, tpucode, gpucode (ตัด BCP NO ออกแล้ว)

แถวสุดท้ายของแต่ละไฟล์ (ยกเว้น gpsc.xls) คือคำอธิบายคอลัมน์ที่พี่โอมเขียนเพิ่ม ไม่ใช่ข้อมูล

**วิธีคำนวณที่เข้าใจตอนนี้:**
- มูลค่าคลังยา = "มูลค่ารวมคงคลัง" จาก inventory.xls ตรง ๆ (รายการที่มีหลายแถว = คนละ lot จะรวมกัน)
- มูลค่าห้องจ่ายยา = จำนวน (unit) × ราคาทุน/หน่วย (costrate จาก Meditem)
- แปลงหน่วย กล่อง ↔ unit ใช้จำนวนบรรจุ/กล่อง (packqty จาก Meditem)
- ชื่อกลุ่ม GPSC = gpscode ใน Meditem → ชื่อกลุ่มใน gpsc.xls

## บันทึก ภย. / ภว. → ขย. / ขว. → ย. / ยว. (Word)

- ปุ่ม "ออกบันทึก ภย. / ขย. / ย. (Word)" ในหน้าทำใบเสนอราคา (เลือกใบที่ส่งออกแล้วในประวัติ) · ใบ W = ภย. / ขย. / ย. · ใบ WM, WC = ภว. / ขว. / ยว.
- ขั้นที่ 1 เลือกคณะกรรมการตรวจรับ 3 คน เจ้าหน้าที่พัสดุ หัวหน้าเจ้าหน้าที่พัสดุ ผู้บริหารเสนอความเห็น ผู้อำนวยการ — รายชื่อ / ตำแหน่ง / บรรทัดลงนาม / หัวกระดาษ ตั้งค่าในโปรแกรม เก็บใน IndexedDB (slot `_memoset`) ของเครื่องนั้นเท่านั้น **ไม่ใส่ชื่อคนในโค้ด** (repo สาธารณะ)
- ขั้นที่ 2 เลขที่ / วันที่: ภย. / ภว. รันตาม พ.ศ. (0001/2569) · ขย. / ขว. รันตามปีงบ และ ย. / ยว. ใช้เลขเดียวกับ ขย. · เลขถัดไปจำไว้ ไม่ย้อนกลับ · หนังสืออ้างอิงแผนจำไว้ต่อปีงบ · เลขที่ / วันที่บิลของบริษัท และกำหนดส่ง (ค่าเริ่มต้น 5 วันทำการ) ใช้ใน ย.
- ขั้นที่ 3 รายการ (แก้ได้ทุกช่อง): ยอดคงเหลือ = คงคลังยา (inventory_exp) · อัตราการใช้ = userate ในไฟล์ list · ขนาดบรรจุ · ราคากลาง = ใบ "ราคากลาง" ใน DATA Template × จำนวนต่อหน่วยซื้อ · ราคาซื้อครั้งสุดท้าย = minpunitcost ของ PO_inven ครั้งล่าสุด · GPU / TPU จาก Meditem · UNSPSC = 8 หลักท้ายของ gpscode (ตัด 990000 นำหน้า)
- ตาราง: คอลัมน์ราคาซื้อครั้งสุดท้ายแสดงเมื่อมีรายการที่ไม่มีราคากลาง · VAT 7% (ราคารวม VAT ÷ 1.07) · ขย. ข้อ 3 ราคากลางของพัสดุ = Σ ราคากลาง × จำนวน (ไม่มีราคากลางใช้ราคาซื้อครั้งสุดท้าย) · ขย. ข้อ 3–8 ขึ้นหน้าใหม่ · ไม่แปะลายเซ็นในบันทึก
- ไฟล์ .docx สร้างในเบราว์เซอร์ด้วยตัวเขียน zip ของ SheetJS (ไม่โหลดไลบรารีเพิ่ม) ฟอนต์ TH SarabunIT๙ · ต้องมี compat mode 15 + applyBreakingRules ใน settings.xml และ `<w:cs/>` ในข้อความไทย ไม่งั้น Word ตัดบรรทัดเฉพาะที่ช่องว่าง (ตัวอักษรถูกยืด)

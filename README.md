## สถานะปัจจุบัน

- ลากไฟล์ที่ export จาก HIS มาวางได้หลายไฟล์พร้อมกัน โปรแกรมจำประเภทไฟล์จากหัวคอลัมน์ (ไม่ต้องตั้งชื่อไฟล์ให้ตรง)
- จำข้อมูลนำเข้าครั้งล่าสุดของแต่ละไฟล์ไว้ในเบราว์เซอร์ (IndexedDB) — ไฟล์ที่ไม่ได้นำเข้าใหม่จะใช้ข้อมูลเดิม ข้อมูลอยู่เฉพาะเครื่อง/เบราว์เซอร์ที่นำเข้า
- Top 10 และตารางแสดงเป็นกล่อง: คงคลัง (กล่อง) + (ชั้น 1 + ชั้น G) ÷ packsize
- ส่งออก Excel: hospcode, generic, tradename, content, packsize, list want, inventory, total floor, floor1, floor G, floor 1 IPD, lot / expdate (รวมทุก lot), distribute, manufact, ised, ndc24, medaccnation_name, medrgttype_name, drugcode, tpucode, gpucode (ตัด BCP NO ออกแล้ว)

**วิธีคำนวณที่เข้าใจตอนนี้:**
- มูลค่าคลังยา = "มูลค่ารวมคงคลัง" จาก inventory.xls ตรง ๆ (รายการที่มีหลายแถว = คนละ lot จะรวมกัน)
- มูลค่าห้องจ่ายยา = จำนวน (unit) × ราคาทุน/หน่วย (costrate จาก Meditem)
- แปลงหน่วย กล่อง ↔ unit ใช้จำนวนบรรจุ/กล่อง ตามลำดับ: packqty ใน inventory_exp → PO_inven ประเภท 101 ครั้งล่าสุด (การรับประเภทอื่นบางรายการลงเป็นชิ้นเดี่ยว จึงไม่ใช้) → dispen_inven ครั้งล่าสุด → Meditem → DrugCatNow (Meditem / DrugCatNow บางรายการไม่ตรงกับกล่องที่คลังยานับจริง · รายการที่ไม่มีการเคลื่อนไหวเลยจึงใช้ค่าจาก Meditem)
- ชื่อกลุ่ม GPSC = gpscode ใน Meditem → ชื่อกลุ่มใน gpsc.xls
- กราฟแยกตามกลุ่ม GPSC: คงคลัง = ยอด ณ สิ้นเดือนที่เลือก (ประวัติคงคลังรายเดือน) · สั่งซื้อ = PO_inven 101 สะสมตั้งแต่ ต.ค. ของปีงบถึงเดือนที่เลือก · ปีงบที่ PO_inven ไม่ครบตั้งแต่ ต.ค. ไม่เทียบยอดสั่งซื้อ

## กราฟมูลค่ารวมตาม GPU: ยอดแผนต่อหน่วยย่อย

ท้ายแท่ง: มูลค่าแผนรวม · จำนวนรวม = Σ กล่อง × จำนวนต่อกล่อง (ขนาดบรรจุจาก planfin ไม่มีใช้ Meditem / DrugCatNow) เพราะแต่ละบริษัทขนาดบรรจุไม่เท่ากัน · ชี้ที่แท่งเห็นทีละยี่ห้อพร้อมราคาต่อหน่วยย่อย = มูลค่าแผน ÷ (กล่อง × จำนวนต่อกล่อง) · รายการที่ไม่รู้ขนาดบรรจุ: ไม่แสดงจำนวนรวมของ GPU นั้น

## รับจากการสั่งซื้อเข้าคลัง: แยกประเภท

ปุ่มรวมทุกประเภท / ยา / เวชภัณฑ์มิใช่ยา / สารเคมีภัณฑ์ ใช้กับกราฟรายเดือนและตารางรายการ · ยา = ทะเบียนยา · สารเคมีภัณฑ์ = ทะเบียนเภสัชเคมีภัณฑ์ · เวชภัณฑ์มิใช่ยา = ทะเบียนอื่นทั้งหมด (ตรงกับชุด W / WC / WM) · ไม่มีทะเบียน = ปุ่ม "ไม่ระบุทะเบียน" แสดงเมื่อมีรายการ

## บันทึก ภย. / ภว. → ขย. / ขว. → ย. / ยว. (Word)

- ปุ่ม "ออกบันทึก ภย. / ขย. / ย. (Word)" ในหน้าทำใบเสนอราคา (เลือกใบที่ส่งออกแล้วในประวัติ หรือใบจากไฟล์ใบเสนอราคาที่ลากเข้ามา) · ใบ W = ภย. / ขย. / ย. · ใบ WM / WC = ภว. / ขว. / ยว. (พี่โอม 9 พ.ย. 69 ตามหมวดในแผน · ใบ WC ที่ออกเลขไปแล้วก่อนหน้านี้เปิดเป็น ภย. ตามเดิม ชุดจำไว้กับบันทึก) · ขั้นที่ 3 แสดงวงเงินแผนคงเหลือของกอง = planfin ปีงบ (ตามวันที่ ขย. หรือ ภย.) − PO_inven 101 ที่รับแล้ว · กองยา W / WB = planfin · กองเวชภัณฑ์มิใช่ยา WM / WC = planfin_M + planfin_C (แถบวงเงินในตารางแผนใช้กองเดียวกัน) · และยอดหลังหักใบนี้ (ไม่หักใบที่สั่งแล้วแต่ยังไม่ได้รับของ)
- ขั้นที่ 1 เลือกคณะกรรมการตรวจรับ 3 คน (ช่องประธานแสดงเฉพาะคนที่ติ๊ก ประธานกรรมการตรวจรับ · ใช้กับ รย. / รยว. ด้วย) เจ้าหน้าที่พัสดุ หัวหน้าเจ้าหน้าที่พัสดุ (ลงนาม ขย. / ขว. / ย. / ยว.) หัวหน้ากลุ่มงานเภสัชกรรม (ลงนาม ภย. / ภว.) ผู้บริหารเสนอความเห็น ผู้อำนวยการ · ใต้ชื่อ = ช่อง "ใช้ลงนาม" (ว่าง = ตำแหน่ง) · 2 หน้าที่ใหม่ (พี่โอม 9 พ.ย. 69) ตั้งต้นครั้งเดียวจากคนเดิม: หัวหน้ากลุ่มงานได้ติ๊กหัวหน้าเจ้าหน้าที่พัสดุ ประธานในชุดที่ใช้แล้วได้ติ๊กประธาน — รายชื่อ / ตำแหน่ง / บรรทัดลงนาม / หัวกระดาษ ตั้งค่าในโปรแกรม เก็บใน IndexedDB (slot `_memoset`) ของเครื่องนั้นเท่านั้น **ไม่ใส่ชื่อคนในโค้ด** (repo สาธารณะ)
- ขั้นที่ 2 เลขที่ / วันที่: ภย. / ภว. รันตาม พ.ศ. (0001/2569) · ขย. / ขว. รันตามปีงบ และ ย. / ยว. ใช้เลขเดียวกับ ขย. · เลขถัดไปจำไว้ ไม่ย้อนกลับ · หนังสืออ้างอิงแผนจำไว้ต่อปีงบ · เลขที่ / วันที่บิลของบริษัท และกำหนดส่ง (ค่าเริ่มต้น 5 วันทำการ) ใช้ใน ย.
- ขั้นที่ 3 คอลัมน์เทียบแผน (หน้าจอเท่านั้น): อัตราการใช้ × 12 เทียบ planfin ทั้งปีของปีงบตามวันที่ ขย. (ไม่ระบุใช้วันที่ ภย.) = อยู่ในแผน / เกินแผน + จำนวนและมูลค่าที่เกิน (ราคาต่อกล่องในแผน) · เกินแผนได้ ไม่ห้ามออกเอกสาร
- ขั้นที่ 3 รายการ (แก้ได้ทุกช่อง): ยอดคงเหลือ = คงคลังยา (inventory_exp) · อัตราการใช้ = userate ในไฟล์ list (ยอดจ่ายจากการขอเบิกเฉลี่ยล่าสุดราว 4 เดือน ตรวจจากไฟล์ 25 ก.ย. 69) · ขนาดบรรจุ · ราคากลาง = ใบ "ราคากลาง" ใน DATA Template × จำนวนต่อหน่วยซื้อ · ราคาซื้อครั้งสุดท้าย = minpunitcost ของ PO_inven ครั้งล่าสุด · GPU / TPU จาก Meditem · UNSPSC = 8 หลักท้ายของ gpscode (ตัด 990000 นำหน้า)
- ชื่อรายการในตาราง ภย. / ขย. / ย. (ข้อ 2.32 ข้อ 6): ตั้งต้นเป็น GENERIC ความแรง (ชื่อการค้า) ตัวพิมพ์ใหญ่ จาก DrugCatNow `generic` + `strength` เช่น ERGOTAMINE TARTRATE 1 MG, CAFFEINE 100 MG (TOFAGO) · ยาผสมจับคู่ตัวยากับความแรงตามลำดับ " + " คั่นด้วยจุลภาค เรียงตามที่ปรากฏในชื่อการค้า · ชื่อการค้า = ชื่อในวงเล็บแรกของ tradename (ไม่ใช่หมายเหตุ รพ.) หรือคำแรกก่อนความแรง / รูปแบบยา · ไม่มี generic หรือหารหัสไม่เจอ = ชื่อเดิมในใบเสนอราคา · ชุด ภว. / ขว. / ยว. และ รย. ใช้ชื่อเดิม · แก้ในช่องได้ก่อนส่งออก · ชื่อไฟล์ .docx ยังใช้ชื่อในใบเสนอราคา · บันทึกที่เปิดไว้ก่อนแล้วกด "ดึงรายการจากใบเสนอราคาใหม่" เพื่อใช้ชื่อแบบใหม่
- คอลัมน์ราคาท้ายตาราง ภย. / ภว. / ขย. / ขว. ตามผู้แทนจำหน่าย (การเงินกำหนด): Zuellig = ราคาต่อหน่วย (รวม VAT) · ราคาต่อหน่วย (ไม่รวม VAT) · วงเงิน (ไม่รวม VAT) — มูลค่าไม่รวมภาษี = ผลรวมคอลัมน์ วงเงินรวม = × 1.07 · DKSH = ราคาต่อหน่วย (รวม VAT) · ราคาต่อหน่วย (ไม่รวม VAT) · วงเงิน (รวม VAT) — มูลค่าไม่รวมภาษี = Σ จำนวน × ราคาไม่รวม VAT · บริษัทอื่น = ราคาต่อหน่วย (รวม VAT) · วงเงิน (รวม VAT) · เลือกอัตโนมัติจากชื่อบริษัท (ซิลลิค → Zuellig · ดีเคเอสเอช / ดีทแฮล์ม → DKSH) เปลี่ยนได้ในขั้นที่ 3 จำไว้กับใบเสนอราคา · ราคาไม่รวม VAT ต่อหน่วย = ราคารวม VAT ÷ 1.07 ปัด 2 ตำแหน่ง (พี่โอมยืนยัน 4 พ.ย. 69 · บริษัทให้ราคาไม่รวม VAT = × 1.07 ก่อนพิมพ์ลงช่องราคา) · ย. / ยว. ยังใช้แบบเดิม
- ย. (ยา) ใช้คอลัมน์ราคาตามบริษัทชุดเดียวกัน (ข้อ 2.32 ข้อ 7): DKSH เพิ่ม ราคาต่อหน่วย (ไม่รวม VAT) ก่อนวงเงิน (รวม VAT) · Zuellig ราคาต่อหน่วย (รวม VAT) · ราคาต่อหน่วย (ไม่รวม VAT) · วงเงิน (ไม่รวม VAT) · บริษัทอื่นเหมือนเดิม · ยว. ไม่เปลี่ยน · ยอดท้ายตารางจาก memoTotals เหมือน ภย. / ขย. · ทำตามแบบในวงเล็บของข้อ 27 ระหว่างรอคำตอบ
- ตาราง: คอลัมน์ราคาซื้อครั้งสุดท้ายแสดงเมื่อมีรายการที่ไม่มีราคากลาง · VAT 7% (ราคารวม VAT ÷ 1.07) · ขย. ข้อ 3 ราคากลางของพัสดุ = Σ ราคากลาง × จำนวน (ไม่มีราคากลางใช้ราคาซื้อครั้งสุดท้าย) · ขย. ข้อ 3–8 ขึ้นหน้าใหม่ · ไม่แปะลายเซ็นในบันทึก
- ไฟล์ .docx สร้างในเบราว์เซอร์ด้วยตัวเขียน zip ของ SheetJS (ไม่โหลดไลบรารีเพิ่ม) ฟอนต์ TH SarabunIT๙ · ตัวอักษรในตารางรายการ: ข้อมูล 14 pt (การเงินกำหนด · `MEMO_TBL_SZ`) หัวตาราง 12 pt (พี่โอม · `MEMO_TBL_HEAD_SZ`) ข้อความอื่น 16 pt · ต้องมี compat mode 15 + applyBreakingRules ใน settings.xml และ `<w:cs/>` ในข้อความไทย ไม่งั้น Word ตัดบรรทัดเฉพาะที่ช่องว่าง (ตัวอักษรถูกยืด)

## บันทึกตรวจรับ รย. / รยว. (Word)

- ปุ่ม "ออกบันทึกตรวจรับ รย. / รยว. (Word)" ในหน้าทำใบเสนอราคา ไม่ต้องมีใบเสนอราคาในประวัติ · รย. ต่อจาก ย. (ยา) · รยว. ต่อจาก ยว. (เวชภัณฑ์มิใช่ยา, เภสัชเคมีภัณฑ์ · 9 พ.ย. 69) · 1 รย. = 1 ย. (พี่โอม 5 พ.ย. 69 #34)
- เลือก "การรับ 1 ครั้ง" จาก PO_inven รับจากการสั่งซื้อ (101) ตามเลขที่รับ `minpno` เพราะ `pono` และ `invdate` ใน HIS ว่าง ไม่มีเลขให้จับคู่กับ ย. อัตโนมัติ · ไฟล์ PO_inven ที่นำเข้าก่อนมีปุ่มนี้ต้องลากใหม่ 1 ครั้ง
- ดึงจากไฟล์: จำนวนรายการ · จำนวนเงิน (ผลรวม `unitcost` ซึ่งเป็นมูลค่าทั้งแถว) · ผู้จำหน่าย (`note` ตัดเลขบิลท้ายชื่อ) · เลขที่เอกสาร (`invno`) · วันที่ตรวจรับ (`minpdate`) · ปีงบประมาณตามวันที่ ขย.
- กรอกเอง: เลขที่ รย. / รยว. (พิมพ์เลขแรก แล้วรันต่อตามปีงบ เหมือน ขย.) · วันที่ · เลขที่และวันที่ ขย. / ขว. (เลือกจากบันทึกในโปรแกรมได้ถ้ามี) · วันที่ของเอกสารส่งของ · เลือกกรรมการ 3 ช่อง (ตั้งต้นจากชุดที่ใช้ล่าสุด) คนแรกเป็นประธาน
- ค่าที่ส่งออกแล้วจำไว้กับเลขที่รับใน `_memoset` (`ry`) และรายการแสดง "ออกแล้ว" · ไม่ห้ามออกซ้ำ · ย. 1 ใบส่งของรอบเดียว (พี่โอมยืนยัน 6 พ.ย. 69) · ถ้อยคำ รยว. เทียบกับตัวอย่าง รยว.0044 แล้ว

## สำรอง / กู้คืนข้อมูล

- ปุ่ม "สำรองข้อมูล" ที่แถบข้อมูลที่ใช้อยู่ ส่งออกไฟล์ `.json` เก็บ ตารางเดือนสำรอง (`_kpi`) · ประวัติใบเสนอราคาและค่าในบันทึก (`_quotes`) · รายชื่อ เลขที่ถัดไป ตราครุฑ และ รย. ที่ออกแล้ว (`_memoset`) · คงคลังย้อนหลัง (`_stockhist`) · เลขใบเสนอราคาใน localStorage (`rj2-quote-next-*`) (#38)
- **ไม่เก็บ DATA Template (`quoteTpl`) เพราะมีลายเซ็นหัวหน้ากลุ่มงาน** และไม่เก็บไฟล์ HIS (ลากใหม่ได้) · เปลี่ยนเครื่อง = กู้คืน แล้วลากไฟล์ HIS และ DATA Template อีกครั้ง
- ปุ่ม "กู้คืนข้อมูล" รับเฉพาะไฟล์สำรองของโปรแกรมนี้ ถามยืนยันก่อน และแทนที่ข้อมูลชุดเดียวกันในเครื่อง · ไฟล์เก่าทำให้เลขที่ถัดไปย้อนกลับ ต้องตรวจเลขก่อนออกเอกสารใบต่อไป
- ไฟล์สำรองมีข้อมูลจริงและรายชื่อ ห้าม commit (`.gitignore` กันไว้)

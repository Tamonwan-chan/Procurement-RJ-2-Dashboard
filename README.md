# Dashboard จัดซื้อ พี่โอม

ระบบติดตามคลังยาและการจัดซื้อของห้องยา รพ.ราชวิถี 2 — ลากไฟล์ Excel ที่ export จาก HIS มาวาง แล้วดูแดชบอร์ดสรุปทันที ทำงานทั้งหมดในเบราว์เซอร์ ไม่ต้องมีเซิร์ฟเวอร์ และไฟล์ไม่ถูกส่งออกไปที่ไหน

ลิงก์ใช้งาน: https://tamonwan-chan.github.io/Procurement-RJ-2-Dashboard/mockup/dashboard-mockup.html

## สถานะปัจจุบัน

- ลากไฟล์ที่ export จาก HIS มาวางได้หลายไฟล์พร้อมกัน โปรแกรมจำประเภทไฟล์จากหัวคอลัมน์ (ไม่ต้องตั้งชื่อไฟล์ให้ตรง)
- จำข้อมูลนำเข้าครั้งล่าสุดของแต่ละไฟล์ไว้ในเบราว์เซอร์ (IndexedDB) — ไฟล์ที่ไม่ได้นำเข้าใหม่จะใช้ข้อมูลเดิม ข้อมูลอยู่เฉพาะเครื่อง/เบราว์เซอร์ที่นำเข้า
- Top 10 และตารางแสดงเป็นกล่อง: คงคลัง (กล่อง) + (ชั้น 1 + ชั้น G) ÷ packsize
- ส่งออก Excel หัวตารางแบบเดิม: hospcode, generic, tradename, content, packsize, list want, inventory, total floor, floor1, floor G, distribute, manufact, ised, ndc24, BCP NO, medaccnation_name, medrgttype_name

## ไฟล์แต่ละไฟล์ใช้ทำอะไร (รูปแบบใหม่)

ทุกไฟล์จับคู่กันด้วย meditem = hospcode

| ไฟล์ | ใช้ข้อมูลอะไร | จำนวนแถว |
|---|---|---|
| Meditem.xls | ทะเบียนหลักของเวชภัณฑ์ทั้งหมด — ชื่อการค้า, จำนวนบรรจุ/กล่อง (packqty), ราคาทุน/หน่วย (costrate), รหัส 24 หลัก, gpscode, รหัส TPU / GPU และรหัสทะเบียน (medrgttype) กับประเภทบัญชี (accnation) ที่ซ่อนไว้ | 9,015 |
| DrugCatNow.xls | ชื่อทั่วไป (generic), ชื่อเวชภัณฑ์ (tradename), content, ผู้แทนจำหน่าย, ผู้ผลิต, จำนวนต่อกล่อง | 4,341 |
| gpsc.xls | แปลงรหัส gpscode เป็นชื่อกลุ่ม (เช่น 99000051101500 = ยาปฏิชีวนะ) | 23,834 |
| inventory.xls | ยอดคงคลังของคลังยา — จำนวน (หน่วยเป็นกล่อง), ขนาดบรรจุ/กล่อง, ราคาทุน/กล่อง, มูลค่ารวมคงคลัง | 411 |
| ห้องจ่ายยา ชั้น G.xls | ยอดคงเหลือห้องจ่ายยาชั้น G (หน่วยเป็น unit) | 974 |
| ห้องจ่ายยา ชั้น 1.xls | ยอดคงเหลือห้องจ่ายยาชั้น 1 (หน่วยเป็น unit) | 1,216 |
| list.xls | รายการแจ้งความต้องการจัดซื้อ — อัตราการใช้ต่ำสุด (lowrate), อัตราการใช้สูงสุด (highrate), จำนวนคงเหลือในคลัง (sumqty), ขนาดบรรจุ/กล่อง, แจ้งสถานะ | 285 |

แถวสุดท้ายของแต่ละไฟล์ (ยกเว้น gpsc.xls) คือคำอธิบายคอลัมน์ที่พี่โอมเขียนเพิ่ม ไม่ใช่ข้อมูล

**วิธีคำนวณที่เข้าใจตอนนี้:**
- มูลค่าคลังยา = "มูลค่ารวมคงคลัง" จาก inventory.xls ตรง ๆ (รายการที่มีหลายแถว = คนละ lot จะรวมกัน)
- มูลค่าห้องจ่ายยา = จำนวน (unit) × ราคาทุน/หน่วย (costrate จาก Meditem)
- แปลงหน่วย กล่อง ↔ unit ใช้จำนวนบรรจุ/กล่อง (packqty จาก Meditem)
- ชื่อกลุ่ม GPSC = gpscode ใน Meditem → ชื่อกลุ่มใน gpsc.xls

## ประเด็นที่รอยืนยันจากพี่โอม

ยืนยันแล้ว: ลากไฟล์ทุกครั้ง (gpsc ไม่ค่อยเปลี่ยน), medrgttype 1–8 = ทะเบียน, accnation = ประเภทบัญชี 12 กลุ่ม, E* = ยาบัญชีที่มีเงื่อนไขโรคเฉพาะ, แสดงเป็นกล่อง, ส่งออก Excel หัวตารางแบบเดิม

ยังรอคำตอบ (ดูรายละเอียดท้ายหน้าเว็บ):
1. inventory หลาย lot — รวมทุก lot (โปรแกรม) หรือเอา lot แรก (สูตร VLOOKUP เดิม)
2. ยอดติดลบในห้องจ่ายยา — นับเป็น 0 บนหน้าจอ / ตัวเลขจริงในไฟล์ส่งออก
3. list want = sumqty ถูกต้องไหม และ lowrate / highrate เทียบกับ sumqty หรือ userate
4. กรองตามสถานะ list (สั่งซื้อ / เบิกจากคลังหลัก) ไหม
5. packsize จาก DrugCatNow (ถ้าไม่มีใช้ packqty ของ Meditem)
6. BCP NO กรอกเอง — ไฟล์ส่งออกเว้นว่างไว้
7. กราฟ / ตัวกรองตามกลุ่ม GPSC
8. สมุนไพร / Covid 19 / สูตรตำรับ นับเป็น ED ไหม, accnation 5 และ 11 อยู่ใน ไม่ระบุ
9. ทะเบียนรังสี / อวัยวะเทียม (ไม่มี IR) เป็นตัวเลือกประจำไหม
10. drugcode / tpucode / gpucode ใช้ทำอะไร
11. packprice ใช้ทำอะไร และห้องจ่ายยาใหม่ปี 70–71 export รูปแบบเดียวกับชั้น 1 / ชั้น G ไหม

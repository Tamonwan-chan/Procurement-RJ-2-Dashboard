# Dashboard จัดซื้อ พี่โอม

ระบบติดตามคลังยาและการจัดซื้อของห้องยา — นำเข้าไฟล์ Excel (ยอดคงคลัง, ยอดแจ้งความต้องการจัดซื้อ, ยอดหน่วยย่อยรายห้อง, บัญชี drug cat) แล้วแสดงผลเป็นแดชบอร์ดสรุป

## สถานะปัจจุบัน

อยู่ระหว่างขั้นตอนออกแบบ — ยังไม่เริ่มพัฒนาโปรแกรมจริง ขั้นตอนแรกคือทำ mockup หน้าตาโปรแกรมส่งให้พี่โอมดูก่อน เพื่อยืนยัน scope และแก้ไขประเด็นที่ยังไม่ชัดเจนใน PRD

## ที่มา — สรุปจาก PRD

**นำเข้าไฟล์ (Import):**
- ยอดคงคลัง (หน่วย Pack)
- ยอดรายการแจ้งความต้องการจัดซื้อ (หน่วย Pack)
- ยอดหน่วยย่อย 2 ห้อง: ห้องจ่ายยาชั้น G, ห้องจ่ายชั้น 1 (เผื่อห้องเพิ่มปี 2570)
- Drug cat — key เข้าเองหรือ import/update บัญชี
- Med Item — ข้อมูลหลักตามคอลัมน์ Excel (hospcode, generic, tradename, content, packsize, list want, inventory, total floor, floor 1, floor G, distribute, manufact, ised, ndc24, gpscode)

**Dashboard ที่ต้องการเพิ่ม:**
- จำนวนยาคงคลัง (เลือกห้อง/All) แยกหน่วยย่อย vs คลังกลาง หน่วยจัดหา (Box/unit)
- สัดส่วนยาบัญชี ED/NED (นับต่อ 100 รายการ)
- อัตราการใช้ยา low rate / high rate
- มูลค่าคงคลังพัสดุตาม gpscode (เลือกห้อง/All)

## ประเด็นที่รอยืนยันจากพี่โอม

ดูรายละเอียดในหน้า mockup — สรุปคร่าว ๆ:
1. Import ซ้ำได้ทุกครั้งหรือต้อง fix โครงสร้าง (ปัญหา hospcode ไม่เรียงลำดับ)
2. เผื่อห้องจ่ายยาเพิ่มในปี 2570–2571 กี่ห้อง
3. "GPU" ในสัดส่วน ED/NED หมายถึงอะไร (พิมพ์ผิดจาก GPU code หรือหมายถึงอย่างอื่น)
4. ต้องมีคอลัมน์ราคาต่อหน่วย เพื่อคำนวณมูลค่าคงคลังตาม gpscode
5. เกณฑ์ตัดสิน low rate / high rate ใช้ค่าอะไร
